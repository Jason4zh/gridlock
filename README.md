# GridLock — 桌面锁定网格（测试版）

把蓝牙鼠标的 PCB 拆下来贴在手机背面，让鼠标充当"手机位移传感器"：
手机在水平桌面上**平移或旋转**时，屏幕上的网格平面要与桌面保持**相对静止**。

## 数学模型

把手机在桌面上的姿态记成一个二维刚体变换 `(pivot, θ)`：

- `pivot`：屏幕中心在桌面坐标系中的位置（px）
- `θ`：屏幕坐标系 → 桌面坐标系的旋转角

桌面上的内容点 `p` 映射到屏幕坐标：

```
s = m + R(-θ) · (p - pivot)        m = 屏幕中心
```

绘制时直接对画布做逆变换（translate → rotate(-θ) → translate(-pivot)），网格就"钉"在桌面上。

两个量的更新：

```
θ      : 陀螺仪 Z 轴角速度积分（或融合姿态的绝对航向）
pivot += R(θ) · Δbody     Δbody = 鼠标相对位移 × gain
```

因为鼠标位移是在**机体坐标系**里测的，所以必须用当前 θ 把它旋到桌面坐标系，再累加到 pivot —— 这是手机一边转一边走时不出错的关键。

### 传感器偏心补偿

鼠标 PCB 不在屏幕中心时，纯旋转会让 PCB 自身位移 `Δθ × r`，鼠标会把它当成平移报上来。
代码里反向扣除：`Δpivot_response = -Δθ × r`，`r` 由面板上两个「旋转支点补偿 X/Y」滑块以毫米为单位给出。
标定方法：把手机原地（不平移）旋转 ±30°，如果网格整体平移，就调这两个滑块直到网格只转不平移。

## 角度来源（「旋转」按钮循环）

| 模式 | 说明 |
| --- | --- |
| 融合姿态（默认） | `TYPE_ROTATION_VECTOR` 的绝对航向，投影到水平面取方位角，**无累积漂移**，推荐 |
| 陀螺仪 | `TYPE_GYROSCOPE` 的 Z 轴积分，延迟最低，但长时间会漂（几十秒到几分钟几度） |
| 关 | 只做平移补偿（上一版行为） |

符号约定：屏幕朝上时，陀螺仪 Z 正值 = 俯视逆时针 → `θ` 减小。
如果实测方向相反（个别机型或竖屏取向下），勾 **旋转反向**。

角度在 `±180°` 处做了 unwrap，转过一圈不会跳变。

## 用法

1. 配好蓝牙鼠标，打开 App。
2. 点 **「捕获鼠标指针」** —— 这一步必须做。Android 默认给的是光标绝对坐标，光标顶到屏幕边就取不到位移；
   指针捕获（`requestPointerCapture`）后光标消失，事件走 `onCapturedPointerEvent`，才有连续相对位移。
3. 手机放平，在桌面上平移、旋转，观察网格是否"钉住"。
4. 校正顺序：
   - **方向**：`X 反向` / `Y 反向` / `交换 X/Y`（PCB 贴装转了 90° 时用交换，三种开关组合覆盖 PCB 的 8 种安装朝向）
   - **比例**：`gain`（0.10–3.00）。把手机沿桌面直线推 ~10 cm，网格走过头就调小，跟不上就调大
   - **旋转**：先看 `旋转` 按钮选的是「融合姿态」；方向反了勾 `旋转反向`
   - **偏心**：原地旋转时有整体平移 → 调「旋转支点补偿 X/Y」
5. 屏幕上和状态栏里的遥测会显示 `pivot / θ / events / dx,dy / 取数方式 / 传感器状态`，
   能直接看出捕获有没有生效、用的是哪条通道。

## 输入模式（「模式」按钮循环）

| 模式 | 取数方式 |
| --- | --- |
| 自动 | 优先 `AXIS_RELATIVE_X/Y`，否则用光标绝对坐标差值 |
| 相对轴 | 强制 `AXIS_RELATIVE_X/Y`（多数设备捕获后走这个） |
| 坐标差 | 强制光标绝对坐标相邻事件差值（未捕获时可用） |
| AXIS | 强制 `AXIS_X/AXIS_Y` 原始值（个别设备在捕获状态下这里是增量） |

## 编译

本机（Android proot Ubuntu）没有 JDK / Android SDK / Gradle，编译走 GitHub Actions 云端：

- 工作流：`.github/workflows/build-apk.yml`
- 触发：push 到 main / master，或在 Actions 页面手动 `workflow_dispatch`
- 产物：`gridlock-debug-apk` artifact，内含 `app-debug.apk`（debug 签名，可直接安装）

技术栈：单 module、纯 framework API、零第三方依赖；`compileSdk 34 / minSdk 24`、AGP 8.5.2、Gradle 8.7、JDK 17。
不需要任何权限（鼠标是输入设备，陀螺仪是普通传感器）。

## 已知限制

- 屏幕固定为竖屏（manifest `screenOrientation="portrait"`），保证鼠标轴与屏幕轴恒定对齐；
  横屏需要改这一项，并重新用「交换 X/Y」校正。
- 只补偿绕桌面法线的旋转（roll/pitch 倾斜不补偿），完全贴合"手机平放在桌面"的场景。
- 蓝牙链路的丢包/延迟会直接表现为网格抖动或漂移，这是鼠标本身的问题。
- 融合姿态需要设备有 `TYPE_ROTATION_VECTOR`；没有的话遥测里会显示"姿态无"，改用陀螺仪模式。
